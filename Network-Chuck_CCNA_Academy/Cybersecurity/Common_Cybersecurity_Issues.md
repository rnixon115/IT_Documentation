## Current State of Cybersecurity

- Cyber threats have changed dynamically since the 1970's. When the World Wide Web (WWW) launched in the 90's, malware grew exponentially across the internet.  File-sharing platforms such as Napster, Kazaa, and others spread infections. To counter malware, McAfee, Norton, and others emerged to protect the public.
- Modern threats have sophisticated processes like ransomware, persistent threats, and AI-driven attacks. Cybercriminals and nation-state agencies exploit cloud weaknesses, legacy systems (Deprecated Software/Hardware), and IoT devices.  Artificial Intelligence enhances cyber threats by automating phishing (Malicious Emails), deepfakes, and stealthy reconnaissance.
- Cybercriminals utilize advanced software applications to bypass detection, target critical infrastructure, and steal confidential data, resulting in financial hardship, legal, and safety risks. Threats continue to multiply, so end-users need to understand basic security concepts and terminology.

| Security Terms | Description | 
| :------------: | :---------: |
| Assets         | Valuable items to the organization; could be a person, equipment, resources, and data. | 
| Vulnerability  | A flaw in the system or design that can be exploited. |
| Threat         | A person, organization, or state that poses a potential danger to assets, data, or network functionality of a company. 
| Exploit        | A mechanism taking advantage of a vulnerability. | 
| Mitigation     | Plans to counteract threats or risks. Network security involves multiple mitigation techniques. |
| Risk           | The probability of threats to an asset negatively affecting an organization. Risk measures an event's probability and consequences. |

### Vector of Network Attacks

- An attack vector is an adjacent path to the organization's network, where the threat actor can gain access to Servers, Hosts, or the network itself. An attack can come from outside or inside the network. A threat can also deny service or applications supporting end-user requests, also called Denial-of-Service (DoS).
- An internal employee can cause harm accidentally or intentionally.
  1. Stealing confidential data to removable media, emailing, messaging software, etc.
  2. Compromising internal servers or networking infrastructure.
  3. Disconnecting a network connection, causing a network outage.
  4. Connecting a malicious USB drive to a corporate computer system.
- Internal threats are more dangerous than external threats. Internal threats have direct access to the building, infrastructure devices, corporate network, resources, and confidential data. Cybersecurity professionals mitigate attacks from internal and external threats using tools and techniques.

### Data Loss

- Data loss or data exfiltration is the intentional or unintentional loss, theft, or leakage of data. Data can be categorized as research and development data, sales data, financial data, human resources and legal data, employee data, contractor data, customer data, etc. Each requires security; if security is weak, undesirable consequences can follow.
  1. Brand Damage and loss of reputation.
  2. Loss of competitive advantage.
  3. Loss of customers.
  4. Loss of Revenue.
  5. Legal action stemming in fines and civil penalties.
  6. Costly to notify affected parties and recover from the breach.
     
 | Data Loss Vectors | Description | 
 | :---------------: | :---------: | 
 | Email/Social Networking | Intercepted email or messages could be captured and reveal sensitive information. | 
 | Unencrypted Devices | Devices without encryption can reveal sensitive data. |
 | Cloud Storage Devices | Cloud storage can be compromised due to weak security. |
 | Removable Media | An internal threat carrying a flash drive can steal confidential data when accessing an unsupervised system. Another risk is that an associate carries confidential data on media; this carries a risk of thieves stealing the media from an associate. | 
 | Hard Copy | Confidential documents should be shredded appropriately. |
 | Improper Access Control | Weak passwords can be brute-forced, giving attackers credentials to access restricted sites. |
