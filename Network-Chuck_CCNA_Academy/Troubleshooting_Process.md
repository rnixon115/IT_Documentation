## Troubleshooting Process

### 1.1.1 Troubleshooting Process Review
1. Determining the issue
   - End-user reports
   - Problem Verification report
2. Gather Contextual Information
   - Manufacturer
   - Make / Model
   - Firmware version
   - Operating System Version
   - Ownership / Warranty
3. Gather Configuration & Topology Information
   - Physical & Logical Topology
   - Configuration Files
   - Log Files
4. Determine if there were any similar issues previously
   - Steps taken
   - Results achieved
### 1.1.2 Seven-Step Troubleshooting Process
1. Define The Problem
   - Determine if there is an issue, and define what the issue is. 
3. Gather Information
4. Analyze Information
5. Eliminate Possible Causes
6. Propose a Hypothesis
7. Test Hypothesis
8. Solve The Problem
