
### Wireless Technologies 

#### Bluetooth
1. Bluetooth Pairing
   - When pairing devices, both devices must be in discoverable mode to find each other.
   - Once paired, the devices will exchange information with each other.
     - Name
     - Bluetooth Class
     - Services that the device can use
     - Technical information, such as the features or the Bluetooth specification that it supports
   - Lastly, there will be a PIN or a passkey to connect the devices officially. Pairing services will store the number, so that it will connect when in range.
