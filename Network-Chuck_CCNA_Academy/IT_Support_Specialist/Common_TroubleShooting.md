
## Display Troubleshooting Quick Guide:
- #### Pixel
  1. Pixels are filled with red, green, and blue (RGB) dots that make up the display and image quality. The more pixels filling the screen, the better the picture quality.
- #### Dot Pitch
  1. When grainy text appears, or pixels are far apart on the screen, it's most likely an issue with DOTS or the distance between pixels.
- #### Brightness
  1. Brightness sets how illuminated the screen is.
- #### Contrast Ratio
  1. This is a measurement of how white and how black a monitor can get. A contrast ratio of 1,000:1 displays dimmer whites and more pale blacks than 4,500:1. To help the customer adjust the contrast, search for "contrast", select Contrast themes, and have them turn on a contrast theme by selecting one from the dropdown menu. Options include Aquatic, Desert, Dusk, and Night sky. These themes create high-contrast displays that can make text and interface elements more visible for certain users.
- #### Aspect Ratio
  1. Aspect ratio defines the ratio of images on the screen. If the resolution is set to a lower dimension than what is recommended, it can make the screen look too narrow or too wide.
- #### Refresh Rate
  1. Refresh rate is measured in Hertz (Hz) and indicates how fast the monitor can redraw the screen. For example, playing a video game requires a higher refresh rate due to the amount of changes on the screen.
- #### Other Troubleshooting Tips
  1. Check the connections and make sure that the cables work. Keep a spare on hand, just in case.
  2. When the display is flickering, make sure that the refresh rate is set to the optimal choice, or change the inverter inside the monitor.
  3. When the display shows horizontal lines or a glitchy screen, check the monitor or computer's hardware. Check the monitor or computer's hardware for a disconnected cable. If the cable is connected, make sure no dust or debris is blocking the GPU cooling system. If there is no dust or obstruction, the GPU may be faulty, and it's time to replace it.
  4. If you're seeing a ghost display, "display is experiencing burn-in". Unplug the power for a few hours. If the problem persists, then try degaussing the screen if applicable. If not, then replace the monitor.
  5. If images on the screen look distorted, then the driver has been corrupted, or the display settings are misconfigured. Update or reinstall the driver in Safe Mode or correct the settings.
  6. Oversized icons and/or images can be resolved by changing the settings or replacing the driver in Safe Mode.

## Printer, Scanners, Faxes

#### User Can't Connect To The Printer

| Reasons | Solutions | 
| :-----: | :-------: |
| Printer isn't powered on | Check that the power cable is securely connected |
| Printer is in sleep mode or in an error state | Press the power button or read the manufacturer's manual. 
| USB cable unplugged or broken | Change out the USB Cable for another |
| Not connected to Wi-Fi | Make sure that the SSID is correct, the password is correct, the printer can handle the security encryption type, and the printer is getting an IP address that isn't "169.254.X.X" |
| The driver is not installed or is corrupted | Uninstall the driver and reinstall the driver |
| Wrong printer selected | Make sure that the printer is added and selected | 

#### Paper Jam

| Reasons | Solutions | 
| :-----: | :-------: |
| Paper Inserted Incorrectly | Access the paper intake and carefully remove the paper jam |
| Rollers are worn or dirty | Clean or replace the rollers if applicable |
| Paper is too thick, curled, or damp | Place the appropriate paper thickness according to the printer manual, and place dry, flat paper in the input tray |
| Overloaded paper tray | Reduce paper stack to halfway of the tray depth, and make sure the stack of paper is neat | 
| Debris, foreign objects, or torn paper inside | Inspect the internal mechanism and remove the object | 

#### Clearing the print Queue

| Reasons | Solutions | 
| :-----: | :-------: |
| Stuck or paused print job | Open print queue and manually cancel all jobs | 
| Print spooler service not responding | restart the print spooler service | 
| Too many jobs waiting | Clear the queue of all jobs |
| Printer not accepting new jobs | Restart the printer and computer | 

#### Toner or Ink Replacement 

| Reasons | Solutions | 
| :-----: | :-------: |
| Toner or ink is low or empty | Replace the toner or ink | 
| Incorrect toner/ink | Verify compatability with printer model | 
| Toner/ink not seated correctly | Remove and reseat the Toner/Ink cart correctly |
| Print quality issues after swap | Run a cleaning or calibration cycle from printer settings | 

#### Blurry or Cropped Scan 

| Reasons | Solutions | 
| :-----: | :-------: | 
| Paper not positioned correctly | Align the paper according to the scanner guidelines | 
| Dust or smudges on scanner glass | Gently clean the scanner glass
