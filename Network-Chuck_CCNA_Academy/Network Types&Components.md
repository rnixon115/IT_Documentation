## Network Types 

### Network Infrastructure
1. End Devices
   - Desktop
   - Laptop
   - Smartphone
   - Printer
   - Telepresence Endpoint
   - IP Phone
   - Wireless Tablet 
   - File Servers
   - Web Servers
   - Mail Servers
2. Intermediary Devices
   - Wireless Router - Connects end devices wirelessly to access the internet and WLAN, but can connect devices through Ethernet. 
   - LAN Switch - Connects multiple LAN devices to the network.
   - Router - Forwards traffic based on rules and addresses.
   - Multilayer Switch - A multilayer switch forwards traffic based on MAC Addresses. 
   - Firewall Appliance - A firewall appliance can range from hardware filtering IP addresses and Port numbers to software filtering through apps, files, and end-device networks. 
   - Modem - Connects homes or small offices to the internet.
3. Network Media
   - Wireless Media
      - Flexibility in connecting a wide range of devices.
      - Provides mobility instead of being stationary.
      - Speed is dependent on how many devices are connected; the more devices, the slower the Wi-Fi speed.
      - Can be a security risk if improperly configured.   
   - LAN Media 
      - LAN connects devices through the Ethernet cable to a swith/router/hub.
      - Has the potential to offer a faster data rate compared to wireless.
      - Provides reliable traffic with little risk of being intercepted.
      - Requires a static location.

### Network Diagrams 

1. PAN - Personal Area Network connects devices through Bluetooth (802.15). Devices such as a keyboard, mouse, speakers, earbuds, smartphone, and printers have the capability of connecting to personal devices over a short distance.
2. LAN - Local Area Network connects devices through Ethernet (802.3) instead of wirelessly (802.11). LAN is set up in a small geographical area and is owned by a homeowner, IT department, SOHO, etc.
3. WLAN - Wireless Local Area Network connects devices in a small geographical area but utilizes radio waves over cable.
4. WMN - Wireless Mesh Networks extend the coverage of signal strength throughout the area by APs repeating the signal or directing traffic to the main node.
5. MAN - Metropolitan Area Network is a network that spans across a campus or a city, utilizing wireless or fiber optics.
6. WAN - Wide Area Network is two or more distinct locations that span a large geographical area. Example (Tokyo, Japan -> Washington, DC )
7. NAS - Network Attached Storage is a local file-level storage device on a network.
8. SAN - Storage Area Network is an enterprise-level storage with high performance and scalable architecture.
